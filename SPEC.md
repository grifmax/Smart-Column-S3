# Smart-Column S3 — спецификация проекта

**Версия документа:** 2.2.54  
**Актуальность:** 2026-06-11  
**Целевая платформа:** ESP32-S3 DevKitC-1 N16R8, 16 MB Flash, 8 MB PSRAM  
**Базовая ревизия железа:** `BOARD_REV_V2_0`

---

## 1. Что это за проект

Smart-Column S3 — это контроллер автоматики колонны и смежных процессов на базе ESP32-S3. Проект управляет нагревом, отбором, насосом, клапанами, мешалкой, логированием, историей запусков, профилями, Web UI, MQTT и удалённым доступом.

Ключевая идея проекта: система не только включает исполнительные механизмы, но и даёт оператору повторяемый инженерный сценарий. Для этого в проекте есть история прогонов, профили с baseline-условиями, `Run Advisor`, `Pre-flight`, объяснения причин и мягкая барокоррекция порогов.

## 2. Основные возможности

- Авто-ректификация с FSM, Watt-Control, Smart Decrement и УНО-циклом

- Затирание

- TFT 3.5" как локальная инженерная панель
- MQTT и Home Assistant Discovery
- Cloud Tunnel и удалённый доступ
- OTA, HTTP Basic Auth и rate limiting

## 3. Аппаратная база

### 3.1 Контроллер

- ESP32-S3 DevKitC-1 N16R8
- 16 MB Flash
- 8 MB PSRAM
- Основная ревизия: `BOARD_REV_V2_0`

### 3.2 Датчики и периферия

- DS18B20 — температурные датчики процесса
- BMP280 — атмосферное давление
- MPX5010DP + ADS1115 — электронный ареометр / pressure-based ABV
- PZEM-004T v3.0 — напряжение, ток, мощность, энергия
- TMC2209 + шаговый двигатель — насос
- Серво и клапаны — фракционная и водяная автоматика
- MCP4725 + MCP6001 — мешалка 0-10 В
- TFT ILI9488 + XPT2046 — локальный экран и touch

### 3.3 Ориентировочный BOM

Это не закупочная смета, а быстрый ориентир для понимания состава:

- Контроллер и питание: ESP32-S3, DIN БП 12 В, DC-DC 5 В
- Датчики: DS18B20, BMP280, ADS1115, MPX5010DP, PZEM-004T
- Исполнительные: SSR, TMC2209, клапаны, серво, MOSFET
- Интерфейс: TFT 3.5", buzzer, touch
- Дополнительно: MCP4725, MCP6001, flow / level sensors

Полная стоимость зависит от конкретной конфигурации колонны и силовой части.

## 6. Режимы работы

Источник типов и фаз: [src/types.h](src/types.h)

### 6.1 Режимы

- `IDLE`
- `RECTIFICATION`
- `DISTILLATION`
- `MANUAL_RECT`
- `MASHING`
- `HOLD`
- `NBK`
- `FERMENTATION`

### 6.2 Типовой сценарий авто-ректификации

```
IDLE -> HEATING -> STABILIZATION -> HEADS -> PURGE -> BODY -> TAILS -> FINISH
```

Что делает автоматика:

- разгоняет куб
- стабилизирует колонну
- отбирает головы
- продувает линию
- ведёт тело по рабочим ограничениям
- переводит процесс в хвосты
- завершает прогон

### 6.3 Адаптивные слои поверх режима

- `Watt-Control`
- `Smart Decrement`
- `Process Indicators v2`
- `Operator Guidance`
- `Confidence score`
- `Run Advisor`
- `Pre-flight`
- мягкая барокоррекция порогов профиля

## 7. Исполнительные механизмы

### 7.1 Нагрев

- SSR-управление ТЭНом
- обратная связь по PZEM
- расчёт и ограничение мощности
- phase-control ветка использует `GPIO45 = zero-cross` и `GPIO46 = TRIAC gate`
- для фазового управления штатно применять `MOC3021/MOC3023`, а не `MOC3063`
- при подключении силового симистора `G` должен быть привязан к ветке `A2`, а не к `A1`

Подробная инженерная памятка по этому узлу:

- [docs/TRIAC_HEATER_WIRING.md](docs/TRIAC_HEATER_WIRING.md)

### 7.2 Насос

- TMC2209
- отдельная FreeRTOS task
- калибровка подачи
- работа по скорости и накопленному объёму

### 7.3 Клапаны и фракционная логика

- вода
- головы
- УНО
- задел под старт/стоп клапан и фракционную станцию

### 7.4 Мешалка 0-10 В

Цепочка:

```
ESP32 I2C -> MCP4725 -> MCP6001 -> 0-10 В
```

Особенности:

- ручной и автоматический режим
- запуск из FSM там, где это уместно
- настройки сохраняются в NVS
- есть сервисный UI и ручное управление в Web

## 9. Интерфейсы оператора

### 9.1 Web UI

Основной интерфейс системы. Через Web UI оператор:

- выбирает режим
- запускает и останавливает процесс
- управляет параметрами
- смотрит live-схему, диагностику, графики и историю
- работает с профилями
- получает `Pre-flight`, `Run Advisor` и explanation layer

### 9.2 TFT

Локальная инженерная панель:

- текущий режим
- температуры и состояние процесса
- быстрый локальный контроль
- резерв на случай, когда основной сценарий идёт с планшета или ноутбука

### 9.3 MQTT / Home Assistant

Поддерживаются:

- telemetry
- discovery
- energy metrics
- команды управления

Подробности: [docs/HOME_ASSISTANT.md](docs/HOME_ASSISTANT.md)

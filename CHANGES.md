# Изменения в веб-интерфейсе ручной ректификации

## Дата: 2026-11-14

### ✅ Что сделано:

#### 1. Расширена панель управления ручной ректификацией
**Файл:** `data/index.html` (строки ~1134-1200)

**Где находится:** Веб-интерфейс → **Режимы** → **Ручная ректификация**

**Добавлено 3 новые подсекции:**

##### Подсекция 1: "Мощность и скорость отбора"
- `mrect-heads-power` - мощность для голов (100-10000 Вт, по умолчанию 2500)
- `mrect-heads-speed` - скорость для голов (10-5000 мл/ч, по умолчанию 300)
- `mrect-body-power` - мощность для тела (100-10000 Вт, по умолчанию 2000)
- `mrect-body-speed` - скорость для тела (10-5000 мл/ч, по умолчанию 600)
- `mrect-tails-power` - мощность для хвостов (100-10000 Вт, по умолчанию 1500)
- Примечание: для хвостов скорость рассчитывается через декремент

##### Подсекция 2: "Автоматическая смена фракций"
- `mrect-heads-volume` - целевой объем голов (0-50000 мл, 0 = ручная смена)
- `mrect-body-volume` - целевой объем тела (0-50000 мл, 0 = ручная смена)
- `mrect-tails-volume` - целевой объем хвостов (0-50000 мл, 0 = ручная смена)
- `mrect-sound-enabled` - чекбокс звукового сигнала (включен по умолчанию)

##### Подсекция 3: "Кнопки управления"
- Обновлена кнопка: "💾 Сохранить все параметры" (onclick="saveManualRectSettings()")
- Существующая кнопка: "🔄 Загрузить" (onclick="loadManualRectSettings()")
- **Новая кнопка:** "↺ Сбросить к умолчанию" (id="mrect-reset-btn")

#### 2. JavaScript интеграция
**Файл:** `data/manual-rect-integration.js` (новый)

**Функционал:**
- Автоматическая инициализация при загрузке страницы
- Загрузка настроек из API: `GET /api/settings/manual-rect`
- Сохранение настроек в API: `POST /api/settings/manual-rect`
- Валидация всех полей перед сохранением
- Мониторинг состояния каждые 2 секунды через `GET /api/status`
- Проверка флага `manualRectContainerChangePending` только для режима `MANUAL_RECT`
- Модальное окно "Смена тары" при достижении целевого объема
- Звуковой сигнал: двойной бип (800Hz + 1000Hz)
- Подтверждение смены тары: `POST /api/process/manual-rect/confirm-container`

**Экспортируемые функции:**
- `window.initManualRectSettings()` - инициализация
- `window.showContainerChangeModal(phaseStr)` - показать модальное окно
- `window.hideContainerChangeModal()` - скрыть модальное окно
- `window.confirmContainerChange()` - подтвердить смену тары

### 🔄 Как это работает:

1. **Пользователь открывает "Ручная ректификация"**
   - JavaScript автоматически загружает настройки из NVS через API
   - Заполняются все поля формы

2. **Пользователь изменяет настройки**
   - Мощность: 100-10000 Вт для каждой фракции
   - Скорость: 10-5000 мл/ч для голов и тела
   - Целевые объемы: 0-50000 мл (0 = ручная смена)
   - Звуковой сигнал: вкл/выкл

3. **Пользователь нажимает "Сохранить все параметры"**
   - Валидация всех полей
   - Сохранение через `POST /api/settings/manual-rect`
   - Сохранение в NVS на устройстве

4. **Пользователь запускает процесс**
   - Выбирает режим "Ручная ректификация"
   - Настраивает остальные параметры (сырец, фазы и т.д.)
   - Нажимает "Старт"

5. **Во время процесса (если заданы целевые объемы)**
   - JavaScript каждые 2 секунды проверяет `GET /api/status`
   - Ищет флаг `manualRectContainerChangePending === true`
   - При обнаружении:
     - Отбор автоматически останавливается (backend)
     - Показывается модальное окно "Смена тары"
     - Воспроизводится звуковой сигнал (если включен)
   
6. **Пользователь меняет тару и подтверждает**
   - Нажимает "✅ Подтвердить смену тары"
   - Отправляется `POST /api/process/manual-rect/confirm-container`
   - Backend сбрасывает флаг и возобновляет отбор
   - Модальное окно закрывается

### ⚠️ Важно:

1. **Не влияет на другие режимы**
   - Изменения работают ТОЛЬКО в режиме `MANUAL_RECT`
   - Автоматическая ректификация, дистилляция и другие режимы не затронуты

2. **Обратная совместимость**
   - Все существующие настройки ручной ректификации сохранены
   - Новые настройки добавлены в конец панели
   - Старые функции `saveManualRectSettings()` и `loadManualRectSettings()` остались

3. **Мощность в Ваттах**
   - Backend конвертирует Ватты в проценты автоматически
   - Формула: `percent = (watts / maxPower) * 100`
   - Для пользователя это прозрачно

### 📋 Для тестирования:

1. Скомпилировать: `bash build.sh`
2. Загрузить по OTA: `bash upload_ota.sh`
3. Открыть веб-интерфейс: `http://192.168.3.166`
4. Перейти: **Режимы** → **Ручная ректификация**
5. Проверить новые поля в конце формы
6. Задать целевые объемы (например, 100 мл для голов)
7. Запустить процесс
8. Дождаться достижения объема
9. Проверить модальное окно и звук

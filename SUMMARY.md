## ✅ ЧТО СДЕЛАНО

### 1. 🛡️ Улучшена устойчивость к отвалам датчиков

**Проблема:** Система слишком часто выдавала ошибки из-за кратковременных сбоев связи с датчиками температуры.

**Решение:**
- Увеличен таймаут датчиков: **5 сек → 15 сек**
- Добавлена фильтрация: авария срабатывает после **3 последовательных отвалов**
- Кратковременные отвалы логируются, но не останавливают процесс

**Файлы:**
- `src/config.h` - изменен `SAFETY_SENSOR_TIMEOUT_MS`
- `src/control/safety.cpp` - добавлена логика фильтрации
- `docs/sensor_stability_improvements.md` - документация

### 2. 🎛️ Упрощены настройки ручной ректификации (Backend)

**Проблема:** 
- Настройки были слишком сложными
- Мощность задавалась в процентах (непонятно)
- Ползунки сразу включали нагрев (опасно)
- Не было автоматической смены фракций

**Решение - Backend:**

#### Новая структура `ManualRectSettings`:
```cpp
struct ManualRectSettings {
  float headsPowerW = 2500.0f;              // Мощность голов (Вт)
  float bodyPowerW = 2000.0f;               // Мощность тела (Вт)
  float tailsPowerW = 1500.0f;              // Мощность хвостов (Вт)
  float headsSpeedMlH = 300.0f;             // Скорость голов (мл/ч)
  float bodySpeedMlH = 600.0f;              // Скорость тела (мл/ч)
  float headsTargetVolumeMl = 0.0f;         // Авто-смена (0 = ручная)
  float bodyTargetVolumeMl = 0.0f;
  float tailsTargetVolumeMl = 0.0f;
  bool fractionChangeSoundEnabled = true;   // Звуковой сигнал
};
```

#### Функционал:
- ✅ Мощность задается в Ваттах (понятно пользователю)
- ✅ Отдельные настройки для голов/тела/хвостов
- ✅ Автоматическая смена фракций по объему
- ✅ Звуковой сигнал + уведомление MQTT
- ✅ Окно "Смена тары" с подтверждением
- ✅ Сохранение в NVS (не сбрасывается)

#### API Endpoints (готово):
- `GET /api/settings/manual-rect` - получить настройки
- `POST /api/settings/manual-rect` - сохранить настройки
- `POST /api/process/manual-rect/confirm-container` - подтвердить смену тары
- `GET /api/status` - добавлены поля `manualRectContainerChangePending`

**Файлы backend:**
- `src/types.h` - новая структура + runtime состояние
- `src/control/modes/manual_rect_handler.cpp` - обновлена логика

# TODO: внедрение TFT HMI v2 в железо

Рабочий чеклист миграции локального меню 480×320 (ILI9488 + XPT2046) на модель
из `docs/TFT_MENU_REDESIGN.md`: плоские страницы, строки с инлайн-управлением,
закреплённый `СТОП ВСЁ`, нижняя панель.

Прототип: `docs/prototype/tft-menu-v2.html` (интерактивный, открывается в
браузере). Текущий экранный слой: `src/drivers/display.cpp` (13,6 тыс. строк,
25 экранов). Правила проекта: `GEMINI.md` — версия + запись в `CHANGELOG.md`
на каждое изменение, host-тесты и сборка перед заливкой.

## Правила работы

- [ ] Каждый пункт заканчивается сборкой `esp32s3` и `pio test -e native_json_tests`
- [ ] Версия и `CHANGELOG.md` обновляются в том же коммите, что и код
- [ ] Заливка на прибор — только по явной команде, с проверкой `/api/version`
- [ ] Старые экраны удаляются последними: пока каркас не закрывает экран, он остаётся рабочим
- [ ] Один пункт = один осмысленный коммит, диффы чужих правок не захватывать

## Ф-1. Клапан охлаждения: бинарный + ток удержания (до UI)

Причина: медленный цикл 1–600 с (сделан в 2.4.130) отменён — клапан не должен
открываться «на время» ради доли потока. Нужен двухпозиционный клапан и PWM
только для снижения тока катушки.

- [ ] `Valves`: убрать `SlowPwm::isOn` из `update()`; выход — 0 или уровень удержания
- [ ] Ввести `Втягивание, мс` (50–2000, по умолчанию 300): при открытии 100 %, затем удержание
- [ ] `Удержание, %` (5–100, по умолчанию 38): заполнение LEDC = `duty × 255 / 100`
- [ ] Частоту LEDC клапана поднять до ~20 кГц (`PWM_FREQ_VALVE`), 1 кГц слышно и «щёлкает»
- [ ] Удалить `coolingPwmPeriodSec` из `EquipmentSettings`, NVS-ключ `cool_pwm_per`, поле в `/api/settings/equipment`
- [ ] Переименовать дескрипторы: `COOLING_PWM_HOLD_PERCENT`, `COOLING_PWM_PULL_MS`
- [ ] Web: убрать `Период цикла PWM`, добавить `Втягивание, мс` и `Удержание, %`
- [ ] Host-тесты: расчёт заполнения из процентов, границы, поведение при 0/100 %
- [ ] Сборка + OTA, проверить на слух отсутствие гула и нагрев катушки

## Риски

| Риск | Что делаем |
|---|---|
| `display.cpp` тянет за собой всю отрисовку | каркас отдельным модулем, старое не трогаем до приёмки |

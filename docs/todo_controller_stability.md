# TODO: стабильность контроллера и дозирование насоса

Рабочий чеклист улучшений архитектуры управления, конкурентного доступа,
safety и сервисного дозирования. Это план работ, не описание уже выполненного.

## Принятые условия

- Датчик давления может отсутствовать в комплектации. Его потеря блокирует
  режим только если датчик включён как контролирующий для этого режима.
- Интервал чтения давления 2 секунды допустим. Нужно контролировать свежесть
  выборки и измерять фактическую задержку safety-реакции, а не уменьшать интервал
  без аппаратной причины.
- Сервисное дозирование остаётся расчётным по шагам насоса, пока в тракте нет
  независимого датчика потока/массы. Интерфейс не должен выдавать расчётный
  объём за независимо измеренный.

поведению; фактическая задержка реакции укладывается в утверждённый предел.

Матрица по текущей реализации (`SAFETY_SENSOR_TIMEOUT_MS = 5000`):

| Режим | Температурные роли, блокирующие при установке | Давление при включённом контроле | Давление при выключенном контроле |
|---|---|---|---|
| RECT / MANUAL_RECT | куб, низ колонны, TSA, выход воды | блокирует при отказе/просрочке | не блокирует |
| DISTILLATION | куб, TSA, выход воды | блокирует при отказе/просрочке | не блокирует |
| NBK | куб, низ колонны, TSA, выход воды | блокирует при отказе/просрочке | не блокирует |
| MASHING / HOLD / FERMENTATION | куб | не требуется | не требуется |
| IDLE | нет | не блокирует | не блокирует |

В demo mode runtime-проверка обязательных датчиков обходится. Период чтения
давления задан 2000 мс, но его достаточность и предельную задержку реакции
нужно подтвердить на оборудовании.

## P2. Калибровка насоса и резервный расчёт по времени

Резервный метод доступен только по явному запросу оператора после завершённого
замера без учтённых шагов. Минимум: 30 секунд и 5 мл ожидаемой подачи; изменение
коэффициента ограничено диапазоном 0.25–4.0×, а за пределами 0.5–2.0× нужно
повторное подтверждение.

- [x] Разрешать расчёт по времени только для явно завершённого замера, когда
  подтверждено, что шаги не посчитаны; не использовать fallback для любой
  ошибки `enterMeasuredVolume()`.
- [x] Не применять калибровку из фазы `PRIMING`; завершение в этой фазе должно
  вернуть понятную ошибку либо отдельное безопасное завершение прокачки.
- [x] Для временного fallback требовать минимальную длительность/ожидаемый
  объём и валидную положительную скорость; отклонять слишком короткие замеры.
- [x] Ограничить допустимое изменение коэффициента относительно текущей
  калибровки и требовать повторного подтверждения при большом расхождении.
- [x] В ответе API и журнале сохранять метод (`steps`/`time`), фазу, длительность,
  заданную скорость, введённый фактический объём и исходный/новый коэффициенты.
- [x] Покрыть переходы `PRIMING`, `MEASURING`, `READY_TO_REVIEW`, нулевые,
  частичные и нормальные шаги host-тестами.
- [ ] Проверить на оборудовании, что временной fallback годится только когда
  двигатель действительно исполняет заданные импульсы; не считать его защитой
  от заклинивания или проскальзывания насоса.

Приёмка: ошибочная фаза или недостоверный/слишком короткий замер не меняет NVS;
резервный метод применяется только при соблюдении явных условий и виден
оператору.

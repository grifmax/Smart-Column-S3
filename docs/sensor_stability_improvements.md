# Улучшения устойчивости системы защиты к кратковременным отвалам датчиков

## Проблема

Система защиты реагировала на каждый кратковременный сбой связи с датчиками температуры, что приводило к:
- Ложным срабатываниям аварий типа `SENSOR_FAILURE`
- Остановке процессов из-за временных проблем со связью
- Частым сообщениям об ошибках при нормально работающих датчиках

## Решение

### 1. Увеличен таймаут датчиков (config.h:154)

```cpp
#define SAFETY_SENSOR_TIMEOUT_MS 15000  // было 5000
```

**Было:** 5 секунд - слишком короткий интервал для реальных условий  
**Стало:** 15 секунд - достаточно для фильтрации кратковременных сбоев, но быстро для реальных проблем

### 2. Добавлена фильтрация последовательных отвалов (safety.cpp:472-473)

```cpp
static uint8_t consecutiveSensorFailures = 0;
static constexpr uint8_t SENSOR_FAILURE_THRESHOLD = 3;
```

**Логика:**
- Счетчик увеличивается при каждом обнаружении отвала датчиков
- Авария `SENSOR_FAILURE` срабатывает только после **3 последовательных отвалов**
- При восстановлении связи счетчик сбрасывается в 0
- Кратковременные отвалы логируются для диагностики

### 3. Улучшенное логирование (safety.cpp:687-689)

```cpp
Logger::logf(1, "Защита: кратковременный отвал датчиков (%d/%d): %s",
             consecutiveSensorFailures, SENSOR_FAILURE_THRESHOLD,
             missingSensors);
```

Теперь в логах видно:
- Количество последовательных отвалов
- Какие именно датчики отвалились
- Прогресс до срабатывания аварии

## Поведение системы

### До изменений
```
[отвал датчика на 2 секунды]
→ SENSOR_FAILURE → остановка процесса → требуется сброс аварии
```

### После изменений
```
[отвал датчика на 2 секунды]
→ лог: "кратковременный отвал (1/3)"
→ датчик восстановился
→ счетчик сброшен → процесс продолжается

[3 последовательных отвала по 15+ секунд каждый]
→ SENSOR_FAILURE → остановка процесса
```

## Параметры настройки

Если нужна другая чувствительность:

- **`SAFETY_SENSOR_TIMEOUT_MS`** (config.h:154) - через сколько считать датчик отвалившимся
- **`SENSOR_FAILURE_THRESHOLD`** (safety.cpp:473) - сколько последовательных отвалов до аварии

## Применимо к режимам

- ✅ Все автоматические режимы (RECTIFICATION, DISTILLATION, NBK, AUTOCLAVE и др.)
- ✅ В режиме IDLE ошибки датчиков подавляются (не блокируют UI)
- ✅ В demoMode ошибки датчиков автоматически сбрасываются

## Безопасность

Система защиты по-прежнему **надежно защищает** от реальных проблем:
- Прорыв паров (TSA)
- Перегрев воды
- Превышение давления
- Скорость роста температуры/давления

**Эти проверки срабатывают мгновенно** - фильтрация применяется только к доступности датчиков.

# Hardware profile автоклава

Статус: **draft, не одобрен для управления оборудованием**.

Этот документ фиксирует границу между тем, что известно из firmware-профиля
платы, и тем, что должно быть подтверждено по реальной обвязке сосуда. Пока
таблица не заполнена и не одобрена, `AUTOCLAVE` не должен появляться в меню и
не может получать силовые команды.

## Факты текущей V2.0

| Узел | Текущее назначение | Можно считать автоклавным? | Причина |
| --- | --- | --- | --- |
| Нагрев, GPIO 5 / triac | Основной нагрев дистиллятора | Нет | Не указан отдельный независимый safety-реле и не подтверждены сосуд, мощность и термозащита. |
| Насос, GPIO 6/7/15 | Отбор / НБК | Нет | Не является автоматически циркуляционным насосом автоклава. |
| Клапан воды, GPIO 16 | Охлаждение дистиллятора | Нет | Не является автоматически сливом или контуром охлаждения герметичного сосуда. |
| Клапаны голов/УНО, GPIO 17/18 | Продуктовые маршруты | Нет | Нельзя использовать как vent, drain или pressure-relief без физического назначения. |
| Давление, ADS1115 A1 | Сигнал давления куба | Недостаточно | Firmware читает сигнал, но нужны калибровка, диапазон, freshness и проверка его связи с сосудом. |
| Температура куба | DS18B20 role `TEMP_CUBE` | Недостаточно | Требуются место установки, диапазон и стендовая проверка. |

Следствие: для `BOARD_REV_V2_0` первый профиль автоклава остаётся полностью
выключенным. В частности, firmware **не** переиспользует насос отбора, клапан
воды или продуктовые клапаны как циркуляцию, слив либо сброс давления.

## Данные для утверждения D-020

Заполнить и утвердить для каждого физического выхода. `Нет` — допустимое
значение; оно отключает соответствующую функцию UI и FSM.

| Возможность | Назначенный выход / sensor | Fail-safe при stop, alarm и reboot | Реальный лимит | Статус |
| --- | --- | --- | --- | --- |
| Паровой нагрев | _не назначен_ | 0 W / механическая защита отдельно | _не задан_ | требуется |
| Охлаждение сосуда | _не назначено_ | _не задано_ | температура/время | требуется |
| Циркуляция воды | _не назначена_ | насос off | расход/время/температура | требуется |
| Слив | _не назначен_ | клапан closed | длительность/подтверждение | требуется |
| Pressure sensor | ADS1115 A1 или иной | нагрев 0 при stale/fault | диапазон, калибровка, max/rise | требуется |
| Температура процесса | _роль и место установки_ | нагрев 0 при stale/fault | диапазон/допуск | требуется |
| Механическая защита | предохранительный клапан / термозащита | независима от firmware | паспортные значения | требуется |

## Обязательные численные limits

Перед включением даже парового режима должны быть указаны и подтверждены:

- `sterilizationTempC`, `temperatureBandC`, `sterilizationDurationMin`;
- `heatPowerLimitW`, допустимый ramp и `heatTimeoutMin`;
- `pressureMaxMmHg` и `pressureRiseRateMaxMmHgMin`;
- пределы и freshness датчиков температуры и давления;
- разрешённая охлаждающая последовательность и `coolingStopTempC`;
- для water mode: отдельные насос, слив и их safe states.

Значение `0` не означает «всегда включено». Для каждого поля оно должно быть
отмечено как `disabled`, `manual` или положительное число с единицей измерения.

## Решение для D-021

Первый релиз может заявлять только `steam`, но только после заполнения таблицы
выше и отдельного safety review сосуда. `water` допускается лишь при отдельном
совместимом циркуляционном насосе; текущий насос отбора не является fallback.

## Критерий approval

Профиль считается одобренным только когда владелец оборудования подтвердил:

1. физические назначения и normal/fail-safe состояния всех используемых
   выходов;
2. калибровку, диапазоны и свежесть pressure/temperature sensors;
3. паспортные pressure/temperature limits и независимые механические защиты;
4. допустимость охлаждения после stop, alarm и потери питания;
5. состав первого релиза (`steam` и, если есть отдельное железо, `water`).

После approval значения переносятся в compile-time board profile и становятся
единственным источником разрешённых действий для D-022–D-026.

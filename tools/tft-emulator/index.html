LOCAL OPERATOR PANEL

Сценарий

Масштаб дисплея

100%

В масштабе 100% область экрана строго 480×320 CSS‑пикселей. При увеличении используется nearest‑neighbor без сглаживания.

Как пользоваться

Все элементы внутри экрана кликабельны. Нижняя панель открывает основные разделы. Для проверки полного маршрута: Режимы → Ректификация → Предпуск → Обновить → Старт.

Это макет поведения HMI: он не обращается к API, GPIO и реальным устройствам.

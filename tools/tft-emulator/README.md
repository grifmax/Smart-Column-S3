# Smart Column S3 — TFT emulator

Автономный кликабельный макет локального TFT ILI9488 (ровно 480×320 пикселей)
из прошивки.
Он предназначен для обсуждения экранов, демонстрации сценариев и проверки
навигации в Windows, без подключения к контроллеру.

## Запуск в Windows

Дважды щёлкните [start-emulator.cmd](start-emulator.cmd) или откройте
[index.html](index.html) в современном браузере. Интернет, Node.js и сервер не
требуются.

## Что в нём есть

- Главная панель, режимы, подготовка профиля и preflight;
- запуск демо-процесса, монитор, управление, пауза и безопасный stop;
- настройки, редактор числовых значений, температуры, safety и события;
- сервис, тест оборудования, калибровка насоса и дозирование;
- переключение светлой/тёмной темы и RU/EN, а также готовые внешние сценарии
  `IDLE`, `RUN` и `ALARM`.
- дискретный масштаб 50–200%; при увеличении исходная область 480×320
  растягивается nearest-neighbor, без сглаживания.

Экран опирается на маршруты и роли из `src/drivers/display.cpp` и
`docs/TFT_MENU_MATRIX.md`. Это именно UI-эмулятор: он намеренно не вызывает
прошивку, REST API, GPIO или реальное оборудование.

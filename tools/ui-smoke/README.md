# UI Smoke Tests

Smoke-тесты для главной страницы (`data/index.html`) и базовой логики управления режимами.

## Что проверяется

- блокировка/разблокировка кнопок режимов;
- подсветка текущего режима;
- логика `pause/resume`;
- подтверждение при переключении режима;
- запрет повторного запуска уже активного режима.

## Запуск

```bash
cd tools/ui-smoke
npm install
npx playwright install chromium
npm test
```

Тесты поднимают локальный HTTP-сервер для `../../data` на `http://127.0.0.1:4173` и мокаются `API`-ответы (`/api/status`, `/api/version` и т.п.).
